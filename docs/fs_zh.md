# 内核文件操作（core/fs）

内核自有的文件系统操作。内核模块必须是包（目录 + `__init__.py`），**绝不允许散装 `.py` 文件躺在 `core/` 根**——本包就是当年 `core/fsops.py` 散装文件的归置结果。

## 模块构成

| 文件 | 职责 |
|------|------|
| `textops.py` | 文本文件读/写原语：WebUI 文件管理器的后端（会话页文件浏览器） |

## 安全模型

- 写入前经 `core.fs.pre_write` hook（blockable，返回 `{"blocked": true}` 可否决），写入后发 `core.fs.post_write`（observe）——这是这两个核心 hook 点的唯一触发处。
- 路径判定走安全子系统的路径沙箱与"先规范化再判包含"工具。
- 文本写入成功后发布 `fs.changed` 事件并镜像到全部 WS 客户端（其他标签页刷新文件树与过期角标），载荷含 path / mtime / session_id。
- 写盘走原子写原语，崩溃不留半截文件。

## 边界

- 面向 LLM 的文件工具（读/写/编辑/glob/grep…）不在这里，在文件工具扩展中；本包只服务内核自身的文件管理面。
- 删除不经这里：一律进回收站软删除。
