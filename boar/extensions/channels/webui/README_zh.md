# WebUI 通道扩展

[English](README.md) | 中文版

## 概述

本扩展为 BoarAi 系统提供现代化的 Web 用户界面。它采用响应式设计，使用 Vue 3 框架、CSS 变量主题系统和组件化架构。

## 功能特性

- **现代化界面**：简洁、响应式设计，支持 CSS 变量
- **Vue 3 框架**：基于组件的架构，使用 Vue Router
- **响应式设计**：支持桌面、平板和移动设备
- **主题支持**：亮色和暗色主题，可自定义颜色
- **API 预留**：预配置的 API 端点，便于后续集成
- **静态文件服务**：提供 CSS、JavaScript 和资源文件

## 导航设计

### 顶部导航栏
- **Logo**：🐗 BoarAi ❖（点击返回主页）
- **标签页**：看板、会话、扩展、数据、设置
- **用户信息**：🔌 Root@Host（点击显示用户菜单）

### 底部状态栏
- **连接状态**：WebSocket 连接指示器
- **内核版本**：系统版本信息
- **延迟**：响应时间（毫秒）
- **运行时间**：系统运行时间计数器
- **内存使用**：当前内存消耗
- **活动连接数**：已连接的客户端数量

## 响应式设计

### 桌面端（> 1024px）
- 完整的导航栏，显示所有标签页
- 完整的状态栏，显示所有信息
- 侧边栏导航（实现后）

### 平板端（768px - 1024px）
- 导航标签页可能只显示图标
- 状态栏显示基本信息
- 可折叠的侧边栏

### 移动端（< 768px）
- 导航栏隐藏标签页，显示 Logo 和用户信息
- 显示底部导航栏
- 状态栏显示最少信息
- 触摸友好的界面

## API 接口

### 系统状态
```
GET /api/status
```
返回系统状态信息，包括 CPU、内存和连接统计。

### 消息接口
```
GET /api/messages?session_id=default&limit=50&offset=0
```
获取会话的消息历史。

```
POST /api/messages/send
{
  "session_id": "default",
  "content": "你好",
  "type": "text"
}
```
发送新消息。

### 扩展管理
```
GET /api/extensions
```
获取所有扩展及其状态的列表。

### 配置接口
```
GET /api/config
```
获取当前配置，包括主题和布局设置。

## 使用方法

### 访问 WebUI

启动 BoarAi 服务器后，通过以下地址访问 WebUI：

```
http://localhost:26620/
```

或使用特定 IP 地址：

```
http://<服务器IP>:26620/
```

### 测试组件

访问组件测试页面，查看导航栏和状态栏的实际效果：

```
http://localhost:26620/test
```

### 开发指南

#### 添加新组件

1. 在 `static/js/components/` 目录下创建新的 JavaScript 文件
2. 使用 Vue 3 组合式 API 定义组件
3. 在 `app.js` 中注册组件
4. 在路由配置中添加路由

#### 自定义主题

编辑 `static/css/variables.css` 文件，可以修改：
- 颜色方案
- 字体样式
- 间距大小
- 圆角半径
- 阴影效果

#### 添加新页面

1. 创建新的 Vue 组件
2. 在 `app.js` 中添加路由
3. 在 `navbar.js` 中添加导航标签
4. 在 `app.js` 中添加底部导航项

## 配置选项

WebUI **不拥有监听地址**。它把 `/` 和 `/static/**` 挂到核心服务器同一个 aiohttp app 上，所以 HTTP、`/api/*`、`/ws` 共用一个端口。绑定地址与端口在服务器侧设置，不在这里：

```bash
# 默认 0.0.0.0:26620（局域网可达）
BOARAI_HOST=127.0.0.1 BOARAI_PORT=27000 python main.py start
```

扩展级选项（`extension.yaml` → `config_defaults`）：

- `theme`：初始界面主题（默认 `"light"`，浏览器会记住用户的覆盖）
- `language`：初始界面语言（默认 `"en"`）
